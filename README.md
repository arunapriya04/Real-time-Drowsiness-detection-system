# 🚗 Real-Time Drowsiness Detection System

## About the Project
A computer vision-based system that detects signs of driver drowsiness in real time using a webcam. It analyses eye closure and yawning patterns to identify potential fatigue and promote road safety.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Key Features
- Real-time face monitoring.
- Eye Aspect Ratio (EAR) calculation.
- Mouth Aspect Ratio (MAR) for yawning detection.
- Adaptive thresholding.
- Consecutive frame-based drowsiness analysis.

## Working Process
1. Captures live video through a webcam.
2. Detects facial landmarks using MediaPipe.
3. Analyses eye and mouth movements.
4. Identifies potential signs of drowsiness.

## Applications
- Driver safety monitoring.
- Transportation and fleet management.
- Road accident prevention research.

## Future Enhancements
- Improved detection with glasses.
- Better performance in different lighting conditions.
- Integration with vehicle alert systems.
